# python-movie-ticket-booking-system
A simple Python movie ticket booking system to book tickets, check seat availability, cancel bookings, and manage remaining seats.
# Python Movie Ticket Booking System

A beginner-friendly Python project that simulates a movie ticket booking system using loops and conditional statements.

## Features
- Book movie tickets
- Check available seats
- Cancel booked tickets
- Update remaining seats automatically
- Menu-driven console program

## Technologies Used
- Python 3

## How It Works
The program starts with 10 available seats and allows users to:
1. Book tickets
2. Check available seats
3. Cancel bookings
4. Exit the program

Seat counts are updated automatically after booking or cancellation.

## Concepts Used
- while loop
- if-elif-else conditions
- Variables and arithmetic operations
- User input handling

```bash
